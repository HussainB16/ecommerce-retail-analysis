# 🛒 E-Commerce Retail Analysis

## Overview
End-to-end exploratory data analysis on a retail dataset 
of 300,000+ transactions across 5 countries using Python Libraries.

## Dataset
- **Rows:** 302,010
- **Columns:** 20
- **Countries:** USA, UK, Germany, Canada, Australia
- **Years:** 2023, 2024
- Dataset Link : https://drive.google.com/file/d/1gAmXJcMvxKIuIcfiLSJ-PMElr8v4NWg8/view?usp=sharing

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Questions Answered
- Which customer segment generates the highest revenue?
- Which product category has the highest Sales volume?
- Which category receives the best customer feedback?
- What are the monthly and yearly revenue trends?

## Key Insights
- USA has the highest number of unique Customers.
- Regular Customer segment contributes ~49% of total revenue.
- Electronics category leads in both sales volume and revenue.
- Pepsi generates most revenue than any product brand and exceeds all brands by great revenue margin.
- All Category has similar Excellent Feedback Percentage but Grocery has least Excellent Feedback Percentage (~29%).
- Electronics category has the highest Avg Rating.
- January and April are the months having highest Sales Volume.
- Sales Starts strongly in January and has a big dip in february and then Sales has a peak in April and then another peak from June to August and Later Months show significant dip
